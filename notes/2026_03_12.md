# Lab Notes: In-Sen Scale, Removing Modality, Differential Evolution

**Date:** 2026-03-12

## Overview

Modality and diversity were working against each other throughout evolution. Replaced the 12-output chromatic encoding with a 5-output In-Sen pentatonic scale, removed modality from the fitness function entirely, and added differential evolution. Result: fitness jumps to ~0.8 in 2 generations instead of 48.

---

## The Modality-Diversity Conflict

The fitness function was `modal * activity * diversity`. Modality rewards staying in-scale; diversity rewards using many different pitch classes. With 12 chromatic outputs, these are directly at odds — using more notes means more chances for out-of-scale notes.

### Solution: Bake the Scale into the Encoding

Switched from 12 chromatic outputs to 5 outputs mapped to the In-Sen pentatonic scale:

```
In-Sen: C, Db, F, G, Bb (semitones: 0, 1, 5, 7, 10)
```

Every note the network can produce is in-scale by construction. Modality is guaranteed, so it can be removed from fitness entirely.

### New Fitness

```python
composite = activity * diversity  # was: modal * activity * diversity
```

## Single Source of Truth for the Scale

Defined `IN_SEN_SCALE` once in `network.py`, everything derives from it:

```python
IN_SEN_SCALE = [0, 1, 5, 7, 10]
DEFAULT_N_OUTPUTS_PER_READOUT = len(IN_SEN_SCALE)  # 5 for In-Sen
```

The mapper imports and uses `IN_SEN_SCALE` directly. Added `pitch_intervals` parameter to `save_argmax_outputs_as_midi()` to support arbitrary scales. Removed `get_n_outputs_for_encoding()` — was a redundant hardcoded mapping.

To change the scale, edit one line.

## Why the Network Can't Evolve Beyond Its Initial Structure

Investigated why evolution plateaus regardless of annealing strategy:

### Weight Threshold Creates a Dead Zone

- Initial sparsity = 10% → 90% of weights start at exactly 0
- Weight threshold = 0.05 → weights below this are ignored
- Mutation scale = 0.001

For a zero weight to become effective: `0 + N(0, 0.001) ≈ 0.001`, still far below 0.05 threshold. Would need ~50 aligned mutations to cross — essentially impossible.

### Mutation Scale vs Weight Scale

Typical weights are ~0.3. Mutation scale of 0.001 is 300x smaller. Sign flips (inhibitory ↔ excitatory) would require ~600 aligned mutations. The weight matrix is nearly frozen.

### Annealing Doesn't Fix It

Even at maximum annealing (10x), scale goes from 0.001 → 0.01 — still 5x below the threshold, 30x below typical weights.

Worse: annealing is based on parent age, and age resets to 0 when a child replaces its parent. The population stays perpetually young. Only stagnant parents age, and by then 10x still isn't enough.

## Differential Evolution

### The Idea

Standard mutation: `child = parent + random_noise`
Differential: `child = parent + F * (better - worse)`

The delta between two fit parents encodes which weights matter and which direction to move. Instead of random exploration, follow the structure of the fitness landscape.

### Implementation

Added `NetworkGenotype.differential(better, worse, F)`:

```python
new_weights = clip(self.weights + F * (better.weights - worse.weights), -1, 1)
```

Applied to network weights, output weights, thresholds, and refraction periods. F = 0.7.

### Offspring Split

- **3/5 gaussian mutation** — 5 annealing strategies (none, scale-up, scale-down, rate-up, rate-down)
- **2/5 differential** — pick base parent, two other parents sorted by fitness, apply delta

### Why the First Differential Jump Is Huge

Generation 1: parents are all random — maximally diverse. The delta `(better - worse)` is enormous. F=0.7 applied to that produces offspring radically different from the base, pushed hard toward the fitter parent's region.

### Why It Tapers Off

After selection, parents converge — they look more alike. The delta shrinks automatically. Differential evolution is self-scaling: big steps when diversity is high, small steps when converged. After the initial consolidation, you're back to fine-tuning.

## Win Tracking

Changed "wins" to count elections to the parent pool, not just the top slot. Tracks three sources:

- **mut** — gaussian offspring that made it into top μ
- **diff** — differential offspring that made it into top μ
- **rnd** — fresh randoms that made it into top μ

Progress line: `wins: mut=X diff=Y rnd=Z (+A/B/C) [DIFF]`

Cumulative and per-generation counts. Tag at end (`[MUT]`, `[DIFF]`, `[RND]`) when there's a new #1 best.

## Key Insight

The pentatonic encoding and differential evolution work together:

- **Pentatonic removes a bad objective** — modality was fighting diversity, creating a Pareto frontier that prevented optimization. Baking the scale in eliminates the conflict.
- **Differential provides structured search** — instead of random noise, mutations follow the direction from worse to better in parameter space. Most impactful when population is diverse (early generations).
- **But the core problem remains** — after the population converges, both differential deltas and gaussian mutations are too small to explore new regions. The weight threshold dead zone still locks topology.
